# Referro

Referro helps job seekers land roles through people, not portals. A user pastes a LinkedIn job URL; the product parses the posting, scrapes likely-warm contacts at the company, drafts personalised outreach, and tracks every conversation through a 16-state lifecycle to offer or close.

**Production:** [getreferro.ai](https://getreferro.ai) — currently shows the old kanban UI; new UX lives on `develop`, deploy pending.
